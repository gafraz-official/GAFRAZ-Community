# GAFRAZ Community Edition

**Your Partner from Reconnaissance to Security Intelligence.**

GAFRAZ Community Edition is a Linux desktop application for authorized reconnaissance and security assessment.

## Current Release

**GAFRAZ Community Edition 1.0 Beta 1**  
Version: `1.0.0b1`

Beta 1 has completed final acceptance testing on a clean Kali Linux 2026.2 virtual machine.

## Beta 1 Highlights

- Desktop security assessment interface
- Authorized domain and URL reconnaissance
- Assessment history
- Results browsing
- JSON, HTML, and PDF reports
- Managed setup for:
  - Subfinder 2.14.0
  - HTTPX 1.10.0
  - DNSX 1.3.0
  - Katana 1.6.1
  - Naabu 2.6.1
- Kali Linux Start Menu integration
- Persistent assessment history and reports

## Beta Scope

GAFRAZ Community Edition Beta 1 supports the implemented **domain and URL assessment workflow**.

IPv4 and CIDR targets may be recognized by the interface, but the dedicated network assessment workflow is not implemented in Beta 1.

## Downloads

Official GAFRAZ Community Edition release downloads are provided through the **Releases** section of this repository.

## Responsible Use

GAFRAZ is intended only for systems, domains, and environments that you own or are explicitly authorized to assess.

Users are responsible for complying with all applicable laws, policies, contracts, and authorization requirements.

## Platform

Beta 1 is currently focused on **64-bit Linux**, with final acceptance testing performed on **Kali Linux 2026.2**.

## Source Code

GAFRAZ is distributed as compiled software.

The application source code is **not published in this repository**.

## Beta Feedback

Beta 1 is intended for controlled testing and feedback.

Please report reproducible installation, stability, assessment, or reporting issues through the official GAFRAZ channels.
